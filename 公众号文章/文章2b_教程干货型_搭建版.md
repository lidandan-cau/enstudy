# 我用 AI 做了一个「读故事背单词」微信小程序——手把手搭建教程

---

> **[封面图建议：微信开发者工具截图 + 小程序阅读页并排，体现从0到1]**

---

传统背单词 App 的问题，不是功能不够，而是**太无聊**。

我做了一个不一样的——用 AI 实时生成一篇短故事，故事里藏着你这个词书级别的生词，读完故事词就记住了。

这篇是完整搭建教程，从零开始，手把手带你做出来。

---

## 这个小程序的技术架构

```
微信小程序前端
    ↓ wx.cloud.callFunction
微信云函数（generateStory）
    ↓ HTTP 调用
AI 接口（生成故事）
    ↓ 返回格式化文本
前端解析 → 渲染阅读页 → 存本地 → 复习系统
```

关键点：小程序不能直接调 AI 接口，需要用**微信云函数**做中转。

---

## 第一步：准备工作

### 1. 注册小程序账号 + 开通云开发

- 注册：[mp.weixin.qq.com](https://mp.weixin.qq.com)（选小程序类型）
- 进入后台 → 云开发 → 开通（有免费额度，够个人用）
- 记下你的 **AppID** 和**云开发环境 ID**

### 2. 安装微信开发者工具

下载安装后，新建项目时：
- 填入 AppID
- 勾选「云开发」
- 语言选 JavaScript

---

## 第二步：搭建项目结构

打开开发者工具，新建以下页面文件（在 app.json 的 pages 数组里添加）：

```json
{
  "pages": [
    "pages/index/index",
    "pages/article/article",
    "pages/review/review",
    "pages/generate/generate",
    "pages/my/my"
  ],
  "window": {
    "navigationBarTitleText": "AI短文记单词",
    "navigationBarBackgroundColor": "#FFFFFF"
  },
  "tabBar": {
    "list": [
      { "pagePath": "pages/index/index", "text": "阅读" },
      { "pagePath": "pages/review/review", "text": "复习" },
      { "pagePath": "pages/my/my", "text": "我的" }
    ]
  }
}
```

## 第三步：写云函数（最核心的部分）

在 `cloudfunctions/generateStory/` 目录下，`index.js` 写调用 AI 的逻辑。

把这段提示词给 AI，让它帮你写云函数：

```
帮我写一个微信云函数 generateStory/index.js，要求：

接收参数：
- vocabBook：词书类型（KET/PET/CET4/CET6/GRE）
- storyType：故事风格（如"玄幻修仙"）
- storyLength：短篇/中篇/长篇
- wordCount：生词数量（7/12/24）
- usedWords：已用过的词列表（需排除）

调用 AI API（使用 node-fetch 调用，接口地址和 key 从环境变量读取）：

给 AI 的提示词模板（写死在云函数里）：
"你是一个英语教学内容创作者。请创作一篇[故事风格]风格的英文短文，面向[词书]级别学习者，
包含恰好[数量]个该级别生词。每个生词必须用格式 [英文单词|音标|中文释义] 嵌入句子，
不得使用以下已出现过的词：[usedWords列表]。
返回 JSON 格式：{title: '标题', content: '正文（含格式化生词）', words: ['word1','word2',...]}"

返回格式：
{ success: true, article: { title, rawContent, words, category } }
或 { success: false, error: '...' }

config.json 里设置 timeout: 60
```

## 第四步：写生成页（generate 页面）

```
帮我写 pages/generate/ 的完整4个文件（wxml/wxss/js/json），要求：

词书选择：KET / PET / 四级 / 六级 / 考研，卡片样式，选中高亮
故事风格：玄幻修仙🔮 / 都市生活🏙️ / 科幻未来🚀 / 历史穿越⏳ / 童话故事🧚 / 悬疑推理🔍
  （再次点击可取消，取消后表示随机）
长度选择：短篇（7词）/ 中篇（12词）/ 长篇（24词）
生成预览区：显示"约X个生词 · 约X分钟阅读"

点击「开始生成」按钮：
1. 读取本地 enstudy_articles，提取所有已用单词（去重）
2. 调用云函数 generateStory，传入选项和 usedWords
3. 生成中显示 loading 动画（三个点跳动）
4. 成功后保存文章到本地存储，跳转阅读页

主色调：#3CAB6E（绿色）
```

## 第五步：写阅读页（article 页面）

阅读页的核心是**解析格式化文本**，把 `[word|phonetic|meaning]` 转成可以点击的高亮词。

```
帮我写 pages/article/ 的完整文件，要求：

内容解析：
- 把 rawContent 里的 [英文|音标|中文] 格式解析成节点数组
- 普通文字 → type:'text'
- 生词 → type:'word'，含 en/phonetic/zh 字段

渲染要求：
- 故事文字段落首行缩进两格
- 生词有下划线高亮，颜色 #3CAB6E
- 点击生词弹出释义卡片（半屏弹出，显示英文+音标+中文）
- 释义卡片点击空白处关闭

顶部显示模式切换（Tab 样式）：
- 中英双语：英文正文+行间中文翻译
- 仅英文：只显示英文，生词高亮但不显示中文
- 仅中文：显示中文翻译
```

---

## 第六步：写复习页（review 页面）

```
帮我写 pages/review/ 的完整文件，要求：

数据来源：从 enstudy_articles 本地存储读取所有文章，提取所有生词

掌握度分类（从 enstudy_mastery 存储读取）：
- 新词：mastery 里没有记录
- 待加强：有记录但未达到"已掌握"标准
- 已掌握：known >= 2 且 known > unknown

顶部 Tab 切换：新词 / 待加强 / 已掌握

复习卡片交互：
- 正面：英文单词居中显示（大字体）
- 点击"翻转"或点击卡片，显示音标+中文释义
- 翻转后出现「认识」「不认识」按钮
- 点击后自动进入下一张，更新 mastery 存储

进度条：当前第X张 / 共Y张
完成界面：显示本轮认识X个、不认识X个，提供「再来一轮」按钮
```

---

## 第七步：环境变量配置（AI 接口 key）

云函数里的 AI 接口 key 不能硬写在代码里，要用**云开发环境变量**：

1. 云开发控制台 → 设置 → 环境变量
2. 添加：`AI_API_KEY` = 你的 API key，`AI_API_URL` = 接口地址
3. 云函数里读取：`process.env.AI_API_KEY`
